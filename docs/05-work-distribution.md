## Initial Coordination Requirement

During the first 3–5 days, all members must jointly approve the vehicle identifiers, signal schema, event envelope, individual-twin schema, fleet-twin schema, REST API contracts, fault scenarios, experiment variables and evaluation metrics. The architectural cleanup is complete when the original single-vehicle workflow still passes and Team Members 1 and 2 can implement their components independently against stable contracts.
