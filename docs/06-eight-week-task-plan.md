## Weekly Coordination Rule

At the end of every week, all members must merge tested work, run the shared regression suite, review risks and dependencies, record implementation or experiment evidence, and agree on the next week's detailed tasks. Optional work must not begin until the three-vehicle workflow, individual twins, fleet twin, dashboard, Velocitas, Kanto and required automated tests are stable.
